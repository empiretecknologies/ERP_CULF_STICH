## 2026-09-09

### Changed
- Allow Rate 0 on SalesQutation Next/Save, and auto-open the item's group after Quick Search edit
- `Empire_ERP/wwwroot/js/Customjs/empr_SalesQutation.js`

### Reason
- `rate == ""` treated 0 as empty, so Next was blocked; edit also stayed on the first group instead of the selected item's group

### Impact
- Rate 0 is valid for proceeding
- Quick Search edit selects the group that contains the loaded item so qty/rate are visible immediately

## 2026-09-08

### Changed
- Redesigned SalesQutation form UI to a POS-style group/item card layout with a save modal
- `Empire_ERP/Controllers/SalesQutationController.cs`
- `Empire_ERP/Views/SalesQutation/Index.cshtml`
- `Empire_ERP/wwwroot/js/Customjs/empr_SalesQutation.js`

- Requested a modern, responsive Sales Quotation UI that reuses Old POS Item Group → Items loading while keeping existing Master/Detail CRUD

### Notes

- Missing item/group images fall back to a Font Awesome placeholder
- Razor CSS media queries in the view use `@@media` so the form compiles
